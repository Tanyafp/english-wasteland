# English Wasteland — учебная RPG

## Актуальная версия: две главы

- [Глава 1 — Убежище 27](https://tanyafp.github.io/english-wasteland/) — первые 10 миссий, простые команды, базовый словарь.
- [Глава 2 — Сигнал с поверхности](https://tanyafp.github.io/english-wasteland/chapter2.html) — 48 миссий в четырёх зонах, 32 новых слова, озвучивание (включая медленное), диалоги, выбор предметов, сопоставление, ввод текста, сборка фраз и порядок действий.
- [Кабинет родителя](https://tanyafp.github.io/english-wasteland/parent.html) — общая история попыток двух глав, освоенные слова, ошибки, индивидуальные задания.
- После каждой зоны главы 2 открывается домашнее задание из 6 упражнений. Есть персональное повторение и итоговый экзамен из 12 заданий.
- За неверный ответ нет наказания; для оценки самостоятельного освоения фиксируется первая попытка, а подсказки учитываются отдельно.
- Глава 2 использует отдельный ключ localStorage и отдельную таблицу Supabase chapter_progress, чтобы никогда не перезаписывать сохранение главы 1. Попытки обеих глав попадают в одну защищённую таблицу attempts, различаются полем chapter.

**Облачная база уже создана и подключена в config.js.** Для автоматической передачи результатов нужно один раз связать браузер ребёнка с родительским кабинетом одноразовым кодом. Не требуется загружать JSON. Если вход родителя ещё не завершён или устройство не подключено, задания всё равно работают и хранятся в localStorage.

> Внимание: в данном репозитории публичны только код и задания. Истории ответов ребёнка не храните здесь. Не помещайте в config.js секретные ключи Supabase. Публикация GitHub Pages и вход родителя настраиваются отдельно.

# Архив исходной инструкции (глава 1)

Это отдельный браузерный проект: статический сайт для GitHub Pages и **необязательная** безопасная синхронизация через Supabase. Первый запуск не требует регистрации или сервера. Возрастная версия без насилия и страшных сцен, с оригинальным игровым оформлением (без оригинальных ассетов Fallout).

## Что включено

| Файл | Назначение |
|---|---|
| `index.html` | Первая глава игры (10 сюжетных миссий), словарь, инвентарь, 6 вопросов домашнего задания, журнал попыток, экспорт JSON |
| `parent.html` | Кабинет родителя: ошибки по словам, домашние работы, экспорт CSV/JSON, выбор слов, текст для подготовки следующего уровня |
| `worksheet.html` | Распечатываемый лист закрепления главы 1, ответы для взрослого |
| `config.js` | Публичные настройки проекта Supabase, пока пустые — локальный режим |
| `cloud.js` | Отправка результатов и родительский вход (без секретных ключей) |
| `schema.sql` | Таблицы, правила безопасности и одноразовое подключение ребёнка |
| `.nojekyll` | Настройка публикации GitHub Pages |

## Шаг 1. Выложить игру в GitHub Pages

1. Войди в свой GitHub и открой https://github.com/new .
2. Назови **новый отдельный репозиторий** `english-wasteland` (не используй репозитории «Это гормоны»). На GitHub Free для Pages репозиторий должен быть **Public**.
3. Распакуй ZIP и загрузи **содержимое папки**, включая `index.html`, в корень нового репозитория (`Add file` → `Upload files` → `Commit changes`). Не загружай только один ZIP.
4. В репозитории открой **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
5. Сайт откроется по адресу, который появится в разделе Pages. Вход игры — `index.html`, кабинет родителя — `parent.html`, печатный лист — `worksheet.html`.

GitHub Pages публикует **содержимое сайта открыто**. Даже при платном GitHub/закрытом репозитории сам Pages-сайт может быть публичным. Поэтому НЕ размещай в нём отчёты ребёнка и конфиденциальные данные. В репозиторий попадает только исходный код игры.

## Шаг 2. Поиграть и проверить сбор без облака

* Открой `index.html`, пройди пару миссий, нажми **«Домашнее задание»**. Сначала доступны только освоенные в сюжете слова.
* В игре в блоке «Учебный прогресс» нажми **«Отчёт JSON»** — получишь файл со всеми попытками.
* Открой `parent.html` в **том же браузере** и нажми **«Прочитать с этого устройства»**, либо перенеси JSON на другой компьютер и загрузи через кнопку выбора файла.
* Кабинет покажет ошибки и составит план следующей главы. Кнопка «Скопировать план для ChatGPT» подготовит запрос с результатами.
* Данные в локальном режиме не переходят между устройствами автоматически. Очистка данных браузера может их удалить. Регулярно сохраняй JSON-отчёт.

## Шаг 3. Настроить автоматический сбор результатов через Supabase

1. Создай новый проект на https://supabase.com/ . Бесплатного тарифа достаточно для домашнего пилота в пределах лимитов; бесплатные проекты могут приостанавливаться после недели неактивности.
2. В проекте открой **SQL Editor**, вставь `schema.sql` целиком и выполни. Не запускай SQL поверх существующей базы со своими данными: схема рассчитана на новый проект.
3. В **Authentication → Providers** включи **Anonymous Sign-Ins** (ребёнку не нужна электронная почта). Обычный вход по email для родителя оставь включённым. Если требуется подтверждение email, заверши регистрацию через письмо.
4. В проекте найди **Project URL** и **Publishable key / anon key**. В `config.js` вставь их в поля `supabaseUrl` и `supabaseAnonKey`. **Не вставляй** `service_role`, `secret key`, пароль БД или личные GitHub-токены — ни в сайт, ни в публичный репозиторий.
5. Обнови `config.js` в GitHub. После публикации открой `parent.html`, зарегистрируй свою родительскую почту, войди. Сайт создаст профиль ребёнка и покажет **одноразовый код**.
6. На устройстве ребёнка открой `index.html` → «Учебный прогресс» → «Подключить к кабинету родителя» и введи код.
7. Теперь сюжетные ответы и домашние задания будут отправляться в Supabase при наличии интернета. Если интернет пропал, игра сохраняет попытки локально и отправит при следующей синхронизации. В родительском кабинете нажимай **«Обновить результаты»**.
8. Ты можешь выбрать слова и нажать **«Выдать задание»**. Новое ДЗ появится в игре после обновления страницы либо нажатия «Синхронизировать».

**На новом устройстве**: в кабинете можно перевыпустить код. Старое устройство после этого больше не сможет отправлять результаты; ранее собранная история попыток останется в базе. Игра попытается восстановить последний прогресс из облака, если он дальше локального.

## Как рассчитываются рекомендации

* Источник — каждая попытка с полями `kind` (сюжет / тренировка / ДЗ), `word`, `correct`, `hint_used`, `created_at`. Варианты ответа тоже сохраняются для разбора ошибки.
* Для самостоятельной проверки приоритет имеют **ответы на домашние задания**. Если их нет, учитываются сюжет и тренировочные задания.
* При не менее чем трёх проверках, точности от 80% и отсутствии подсказок слово предварительно считается усвоенным. При двух ошибках или точности ниже 60% — нужно повторение. Это рабочие критерии, а не объективный диагноз знания языка.
* Родительский кабинет делает план следующей главы с приоритетными словами. **Следующая глава пока не генерируется сама**: кнопка копирует подробный запрос для ChatGPT, чтобы мы могли создать её по результатам.

## Педагогический режим на неделю

* **День 1:** 15–20 минут сюжета (первые миссии, HELLO, ROBOT, KEY), 5 минут устно повторить.
* **День 2:** следующие миссии с TAKE, DOOR, OPEN; затем самостоятельное ДЗ из шести вопросов.
* **День 3:** распечатать `worksheet.html`: соединить слова, восстановить команды, сказать 3 фразы вслух.
* **День 4:** завершить главу и выполнить ДЗ. Повторять слова, которые отмечены как проблемные.
* **Через неделю:** ещё раз пройти короткое ДЗ и посмотреть, какие слова удержались без подсказки. На основе результатов готовить главу 2.

Не нужно требовать идеального произношения. Первые цели — распознать слово, связать его с действием, вспомнить значение без перевода и постепенно начать использовать слова самостоятельно.

## Защита данных ребёнка

* Используй псевдоним (например, `Explorer`), не указывай настоящее имя, дату рождения, адрес, школу или другие сведения.
* В публичном GitHub лежат **только** код и учебные материалы, не персональные результаты. В Supabase таблицы ограничены RLS: ученик пишет свои ответы, взрослый видит и назначает задания в своём семейном профиле.
* Родитель входит по email, ребёнок — через анонимную сессию и одноразовый код, без логина и пароля.
* Для реального использования лучше проверить политику хранения данных, доступы, настройки резервного копирования и требования к работе с данными детей в твоей юрисдикции. **Не выкладывай** отчёты в публичные GitHub Issues, репозиторий, README или Pages.

## Ограничения текущей версии

* Облачный режим нельзя проверить до создания твоего Supabase-проекта и внесения публичных настроек. На данный момент он подготовлен, но **не активирован**.
* Пока поддерживается один ребёнок на один родительский аккаунт через интерфейс, хотя база рассчитана на расширение.
* Нет генерации новых уровней в реальном времени; вместо этого кабинет готовит персональный план для следующей сборки игры.
* Озвучка через встроенное распознавание/синтез речи браузера, поэтому наличие английского голоса зависит от устройства.

# My English Week — неделя 1 (16–20 ноября 2026)

Самостоятельное браузерное приложение для изучения английского взрослым, без аккаунта, сервера и платных API. Это **отдельная папка** внутри репозитория: RPG и занятия Святослава в /tutor/ не изменены. У взрослого приложения самостоятельный ключ localStorage, поэтому прогресс не смешивается с детским.

## Открыть

https://tanyafp.github.io/english-wasteland/tanya-english/

Для озвучки удобнее последние версии Chrome / Edge. Все тексты доступны и без микрофона.

## Восемь блоков каждого занятия

1. Диалог — общий и построчный синтез речи, текст и перевод.
2. Новые слова — 12 карточек с произношением, по пятницам 16 слов из понедельника–четверга.
3. На слух — выбор смысла услышанной фразы, медленный темп.
4. Понимание — вопросы по смыслу текста.
5. Собери фразу — составление предложения из слов.
6. Напиши — короткий письменный ответ, допускаются верные варианты написания; голосовой ввод можно исправить перед проверкой.
7. Говори — короткие фразы вслух с образцом, микрофон необязателен.
8. Память — проверка всех слов урока на перевод, повтор неверных ответов.

Два выбора произношения — British / American, переключатель скорости 0.65–1.1, прослушивание каждой реплики. Справочник текста, перевода, слов и правила доступен при выполнении любого упражнения.

## Прогресс и приватность

- Все результаты, ошибки, время и статистика по словам сохраняются в **localStorage только этого браузера**.
- Можно выйти и вернуться к тому же уроку. Между разными браузерами и устройствами синхронизации **нет**.
- «Скачать прогресс» создаёт JSON. «Восстановить» загружает прежний JSON в этот браузер.
- Публичный GitHub содержит только текст уроков и код. **Не коммитьте личные отчёты в GitHub.**
- SpeechSynthesis (озвучка) использует установленные голоса/службы браузера; это не отдельная библиотека готовых MP3. Голос зависит от браузера и операционной системы.
- Web Speech API для микрофона, если он доступен, может обрабатывать голос через сервис браузера. Приложение само никуда не отправляет аудио и не хранит его.
- Распознанный текст не является оценкой фонетического произношения. Фраза вслух может отмечаться вручную.
- Учебное время учитывается, когда вкладка видна и активна и были взаимодействия в последние две минуты либо идёт озвучка. Без активности не засчитывается.

# English Tutor — версия без игры

Новая программа в отдельной папке tutor/; существующая RPG не изменена.

## Что уже работает
- Семь последовательных уроков A1–A1+: слова, чтение вслух, вопросы по смыслу текста, грамматика, проверка памяти.
- Минимум 30 активных минут. Таймер идёт при открытом активном окне и действиях в последние 90 секунд. Время нельзя просто отсидеть с закрытой вкладкой.
- Каждое слово требует трёх правильных ответов подряд. При ошибке текущая серия сбрасывается, история ошибок сохраняется.
- Родительский кабинет с PIN: результаты, ошибки, назначение урока и до 12 дополнительных слов, скачивание JSON.
- Голосовое чтение через браузер; при проблемах с микрофоном есть ручная отметка. Распознавание речи НЕ является настоящей фонетической оценкой.
- Необязательный местный компонент Windows контролирует процесс steam.exe до завершения урока, не трогая папки с играми.

## Попробовать онлайн
https://tanyafp.github.io/english-wasteland/tutor/

GitHub Pages служит для знакомства с уроками. При открытии по этому адресу Steam не блокируется. Для Windows-контроля нужно запускать программу локально.

## Установка на компьютер Святослава
1. В https://github.com/Tanyafp/english-wasteland нажми Code → Download ZIP.
2. Распакуй ZIP в постоянную папку, например C:\EnglishTutor. Не запускай файлы прямо из ZIP.
3. Установи Python 3, если его нет: https://www.python.org/downloads/windows/ . При установке желательно отметить Add Python to PATH.
4. В распакованной папке открой tutor и запусти двойным кликом start-windows.cmd.
5. В браузере откроется http://127.0.0.1:8765/ — это локальный учебный сайт и подключённый контроллер Steam.
6. Убедись, что в статусе Steam написано «Закрыт». Если видишь «Не подключён», защитник не запущен. Окно защитника можно свернуть, но нельзя закрывать.
7. После полного урока длительностью минимум 30 активных минут Steam автоматически разрешается до конца сегодняшнего дня.

Защитник в этом прототипе запускается вручную при каждом включении Windows, а не как служба. Если защитник не запущен, Steam доступен. Если ребёнок с правами администратора захочет обойти ограничение, сможет; защита ориентирована на честную договорённость.

Перед запуском защитника закрой Steam и сохрани прогресс в играх: защитник может принудительно закрыть Steam при попытке его запуска до урока. Он проверяет только Steam.exe, а не все запускаемые напрямую игры.

## Родительский кабинет
Нажми «Родительский кабинет». При первом открытии установи свой PIN (от четырёх символов). Внутри можно увидеть историю ответов, количество ошибок, время занятий и выдать один из семи уроков плюс дополнительные слова. PIN защищает только от случайного входа, не от технически опытного пользователя.

Результаты сохраняются в локальном хранилище браузера для адреса http://127.0.0.1:8765/. При очистке данных браузера они могут пропасть. Скачивай JSON-отчёт как резервную копию.

Для просмотра отчётов с другого устройства потребуется следующий этап — отдельное подключение к существующему Supabase с безопасной схемой. Нынешняя версия **ещё не отправляет** данные в облако.

## Технические и педагогические ограничения
- Это первый комплект из семи уроков, а не разговорный ИИ-репетитор. Темы и задания пока заранее подготовлены.
- Chrome может отправлять распознаваемый голос в свою облачную службу. При отсутствии интернета работа микрофона не гарантируется.
- Оценка «слово освоено» означает три правильных ответа подряд в приложении. Это не гарантия долговременного запоминания: слова нужно проверять повторно в следующих уроках.
- Ограничение Steam не является противовзломной защитой. Программа не переносит файлы Steam, не устанавливает драйверы и не меняет права Windows.
- Не публикуй отчёты и данные ребёнка в публичном репозитории, в Issues или в файлах README.

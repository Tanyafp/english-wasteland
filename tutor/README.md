# English Tutor — 4 недели английского без игры и без Steam-блокировки

Новое расписание **стартует в понедельник 16 ноября 2026 года**. Предыдущая RPG в корне репозитория не изменена.

## Расписание на 4 недели

- **Понедельник—четверг:** новый урок, минимум 30 минут активных занятий и все обязательные упражнения.
- **Пятница:** проверка за четыре предыдущих учебных дня, минимум 45 минут активной работы.
- **Суббота и воскресенье:** свободные дни без назначенных уроков.
- Всего **16 тематических уроков и 4 итоговых пятницы**, то есть **20 учебных дней**. Первые четыре недели заканчиваются 11 декабря 2026 года. На следующую неделю новый контент пока не назначен: курс не повторяется автоматически.
- Программа открывает тему по локальной дате компьютера; по календарю можно вернуться к пропущенному занятию и доделать его.
- Пятничная проверка строится из четырёх тем текущей недели. Если взрослый меняет тему буднего дня в кабинете, пятничный набор меняется вместе с ней.

### Темы по неделям
1. **16–20 ноября:** Мой обычный день; В школе; Семья и друзья; Еда и покупки; большая пятничная проверка.
2. **23–27 ноября:** Увлечения; Мой город; Мои выходные; Поездка на поезде; пятничная проверка.
3. **30 ноября – 4 декабря:** Техника дома; Прогулка в лесу; Полезные привычки; Планы на выходные; пятничная проверка.
4. **7–11 декабря:** Школьный проект; Необычное письмо; Потерянный билет; Учимся вместе; пятничная проверка.

## Сколько упражнений и что проверяется
Обычный урок включает семь разделов: восемь карточек-перевёртышей, чтение одного текста вслух, четыре вопроса к тексту, четыре грамматических упражнения, восемь заданий с выбором перевода, пять письменных проверок и три коротких повторения. Это около 33 небольших действий за день, все разделы можно открывать в любом порядке. Текст доступен постоянно.

По пятницам повторяются четыре текста, выбирается перевод 16 базовых слов (плюс до 2 дополнительно назначенных слов из каждого дня), задаётся восемь вопросов по текстам, восемь заданий по грамматике, восемь письменных проверок и шесть упражнений на закрепление. Чтение и 16 карточек также входят в пятничный урок.

Если ответ неверный, программа не засчитывает упражнение и возвращает к нему. Завершение фиксируется только когда **все семь разделов пройдены** и прошло необходимое активное время. Оставленная без взаимодействия вкладка не должна превращаться в «отсиженный» урок.

## Как работает переход на следующий день
При каждом открытии программы выбирается **сегодняшняя дата**. Для каждого дня создано отдельное сохранение, поэтому:
- уже пройденные упражнения остаются пройденными;
- если урок не закончен, можно продолжить с того же места (или выбрать другой раздел);
- следующий учебный день автоматически показывает следующую тему;
- если открыть программу в выходной, показывается отдых и календарь пропущенных заданий;
- в пятницу автоматически появляется недельная проверка независимо от того, были ли сделаны предыдущие дни — пропуски остаются видны в кабинете родителя.

Родительский кабинет по PIN показывает время, ошибки и статусы каждого дня, позволяет выбрать дату и поменять тему или дополнительные слова. До реальной синхронизации все данные **только в том же браузере на том же устройстве**.

## Открыть в браузере
https://tanyafp.github.io/english-wasteland/tutor/

Сначала обнови страницу через Ctrl+F5. Старые результаты сохраняются благодаря неизменному ключу хранения english-tutor-v1 в браузере. Если очистить данные браузера или открыть другой браузер / компьютер, сохранения там отсутствуют. Кнопка **Скачать отчёт JSON** в кабинете родителя позволяет сохранить резервную копию; импорт отчёта пока не реализован. Никакие результаты ребёнка не отправляются в публичный GitHub.

## Локальная версия на Windows
1. Открой https://github.com/Tanyafp/english-wasteland → Code → Download ZIP.
2. Распакуй ZIP в постоянную папку.
3. Установи Python 3 (если требуется) и из распакованной папки tutor запусти start-windows.cmd.
4. Программа откроется по адресу http://127.0.0.1:8765/.

**Steam и другие программы не блокируются.** Файл windows_guard.py сохранён под старым названием исключительно для совместимости с уже подготовленным запуском; теперь это простой локальный веб-сервер без управления процессами. Новую автозагрузку защитника настраивать не нужно. Если у тебя уже запущен старый Steam-защитник из ранее скачанной сборки, закрой его окно и отключи его ярлык автозагрузки; старые локальные файлы автоматически не обновляются из GitHub.

**Важно:** локальная версия и GitHub Pages — разные адреса сайта с разными хранилищами. Если ребёнок начал занятия по ссылке GitHub Pages, продолжай на этом адресе, чтобы не потерять видимость истории. Не надо переходить на локальную версию ради Steam, раз блокировка не нужна.

## Голос и оценка
Распознавание в браузере иногда путает слова. Поэтому голосовой ответ сначала вписывается в поле, **не оценивается автоматически** и может быть исправлен перед нажатием «Проверить». При сбое микрофона можно ответить текстом. Чтение вслух даёт только приблизительное совпадение распознанных слов, не настоящую оценку фонетики.

## Ограничения
- Курс пока ограничен четырьмя неделями. Новые занятия после 11 декабря нужно добавить отдельно.
- Прогресс сохраняется в localStorage браузера, облачная синхронизация ещё не включена.
- Родительский PIN — простая защита от случайного входа, не административная защита Windows.
- Оценка «ответ верный» означает успех конкретной задачи, но не гарантирует долговременную память. Пятничные проверки и последующее повторение помогают проверить удержание знаний.
- После изменения назначенных уроков не рекомендуется менять темы уже начатых дней: может измениться набор вопросов при старом прогрессе.
